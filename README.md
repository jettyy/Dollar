# 💱 환율 급변동 알림 (달러 · 엔화 → 텔레그램)

달러(USD/KRW)와 엔화(JPY/KRW, 100엔 기준) 환율을 주기적으로 확인해서,
**5분 전과 비교해 설정한 % 이상 오르거나 내리면** 텔레그램으로 메시지를 보내주는 프로그램입니다.
설정과 현황은 브라우저 화면(UI)에서 확인·변경할 수 있습니다.

## 실행 방법

[Node.js](https://nodejs.org) 18 이상만 설치되어 있으면 됩니다. 외부 패키지가 없어서 `npm install`은 필요 없습니다.

```bash
git clone https://github.com/jettyy/Dollar.git   # 처음 한 번
cd Dollar
git pull        # 최신 버전 받기
npm start       # 실행 → 브라우저가 자동으로 http://127.0.0.1:3000 을 엽니다
```

- 종료: 터미널에서 `Ctrl + C`
- 포트 변경: `PORT=3001 npm start` (Windows PowerShell: `$env:PORT=3001; npm start`)
- 브라우저 자동 열기 끄기: `NO_OPEN=1 npm start`
- 브라우저 창은 닫아도 됩니다. **터미널(프로그램)이 켜져 있는 동안** 계속 감시하고 알림을 보냅니다.

## 텔레그램 설정

1. 텔레그램에서 **@BotFather** 검색 → `/newbot` → 봇 이름을 정하면 **봇 토큰**을 받습니다.
2. 만든 봇과 대화방을 열고 아무 메시지나 보냅니다. (그룹 알림을 원하면 봇을 그룹에 초대 후 메시지 전송)
3. 화면의 **봇 토큰** 칸에 토큰을 넣고 **찾기** 버튼 → 채팅 ID가 자동으로 입력됩니다.
4. **테스트 메시지 보내기**로 확인 후 **설정 저장**.

## 설정 항목

| 항목 | 기본값 | 설명 |
| --- | --- | --- |
| 달러 / 엔화 기준 % | ±0.3% | 비교 시점 대비 이 % 이상 변하면 알림 (통화별로 켜고 끌 수 있음) |
| 비교 시간 | 5분 | 몇 분 전 환율과 비교할지 |
| 확인 주기 | 60초 | 환율을 조회하는 간격 |
| 재알림 대기 | 10분 | 같은 통화 알림을 연달아 보내지 않는 시간 (0이면 조건 만족 시마다 전송) |
| 데이터 출처 | 자동 | Yahoo Finance → 네이버 금융 → 두나무 순서로 시도. `모의 데이터`는 테스트용 |

알림 예시:

```
🔺 달러 환율 급등 🇺🇸 USD/KRW

현재: 1,392.50원 (1달러)
5분 전: 1,385.00원
변동: +7.50원 (+0.54%)

알림 기준: ±0.3% · 출처: Yahoo Finance
🕒 2026. 9. 26. 14:05:03
```

## 참고

- 설정(텔레그램 토큰 포함)과 수집 데이터는 `data/` 폴더에 저장되며 git에 올라가지 않습니다. 그래서 `git pull` 해도 설정이 유지됩니다.
- 프로그램을 켠 직후에는 비교할 과거 데이터가 없어서, **비교 시간(5분)이 지난 뒤부터** 알림이 동작합니다.
- 서로 다른 출처의 시세는 비교하지 않습니다 (출처 간 가격 차이로 인한 잘못된 알림 방지).
- 주말·휴일처럼 시장이 쉬는 동안에는 환율이 거의 변하지 않아 알림이 오지 않습니다.
- 보안을 위해 서버는 기본적으로 이 컴퓨터(127.0.0.1)에서만 접속됩니다. 다른 기기에서 접속하려면 `HOST=0.0.0.0 npm start`.
- 테스트: `npm test`
