달러 · 엔화 환율 변동을 감시해 텔레그램으로 알려드려요

연결 중…
텔레그램이 아직 설정되지 않았어요. 아래 텔레그램 설정에서 봇 토큰과 채팅 ID를 입력해야 알림을 받을 수 있어요.

텔레그램 설정

봇 토큰 / 채팅 ID 얻는 법
  1. 텔레그램에서 @BotFather 검색 → /newbot 입력 → 이름 정하면 봇 토큰을 줘요.
  2. 만든 봇을 검색해 대화방을 열고 아무 메시지나 보내세요. (그룹이면 봇을 초대 후 메시지 전송)
  3. 위에 토큰을 넣고 찾기를 누르면 채팅 ID가 나타나요. 클릭하면 입력돼요.
